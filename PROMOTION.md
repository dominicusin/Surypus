# Promotion Strategy

This document describes how to promote Surypus and find new users.

## Target Audience

### Primary Users

- **Small to medium businesses** needing an ERP/CRM system
- **Haskell developers** interested in formal verification
- **Organizations** valuing type safety and correctness
- **Startups** looking for a solid foundation

### Secondary Users

- **Students** learning Haskell and formal methods
- **Researchers** in formal verification
- **Consultants** building solutions for clients

## Value Proposition

**What makes Surypus unique:**

1. **Formally verified** - LiquidHaskell refinements prove invariants
2. **Type-safe database** - Persistent + Esqueleto prevent SQL injection at type level
3. **Event sourcing** - Complete audit trail, event replay
4. **Production-ready** - 61+ CI/CD workflows, comprehensive testing
5. **Open source** - MPL-2.0 license, community-driven
