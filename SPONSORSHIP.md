# Sponsorship

Thank you for considering sponsoring Surypus! This document explains sponsorship tiers, benefits, and how to become a sponsor.

## Why Sponsor?

By sponsoring Surypus, you:

- **Support open source** - Help maintain a production-ready ERP/CRM system
- **Get visibility** - Logo placement and recognition in the community
- **Influence roadmap** - Higher tiers get input on project direction
- **Support your business** - If you use Surypus, sponsorship ensures its longevity

## Sponsorship Tiers

### Individual Sponsors

| Tier | Monthly | Benefits |
|------|---------|----------|
| Supporter | $5 | Name in SPONSORS.md, supporter badge |
| Fan | $25 | Supporter + priority issue responses |
| Advocate | $100 | Fan + logo on README |

### Corporate Sponsors

| Tier | Annual | Benefits |
|------|--------|----------|
| Bronze | $1,000 | Logo on README, priority support |
| Silver | $5,000 | Bronze + featured in release notes |
| Gold | $10,000 | Silver + roadmap influence |
| Platinum | $25,000 | Gold + dedicated support |

## Benefits Details

### All Sponsors

- Name listed in [SPONSORS.md](SPONSORS.md)
- Name listed in release notes
- Access to sponsor-only updates (coming soon)

### Bronze+ Sponsors

- Logo on README.md
- Priority issue responses (48 hours)
- Quarterly project updates

### Silver+ Sponsors

- Featured in release notes
- Logo on project website
- Social media mentions

### Gold+ Sponsors

- Input on roadmap decisions
- Early access to new features
- Direct communication with maintainers

### Platinum Sponsors

- Dedicated support channel
- Custom feature development
- On-site training (if applicable)

1. Visit [opencollective.com/surypus](https://opencollective.com/surypus)
2. Click "Contribute"
3. Choose your amount and frequency
