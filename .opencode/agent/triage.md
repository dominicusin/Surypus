## Метки

### windows

Используйте для любой проблемы, в которой упоминается Windows (операционная система). Убедитесь, что указано, что проблема связана с Windows.

- Используйте, если упоминается также WSL.

#### perf

Проблемы, связанные с производительностью:

- Низкая производительность
- Высокое использование оперативной памяти
- Высокое использование ЦП

**Добавляйте** только в том случае, если это, вероятно, проблема с оперативной памятью или ЦП. **Не добавляйте** для замедления работы LLM.

#### desktop

Проблемы с настольными приложениями:

- Команда `opencode web`
- Само настольное приложение

**Добавляйте** только в том случае, если это касается именно настольного приложения или представления `opencode web`. **Не добавляйте** для проблем с терминалом, TUI или общих проблем с OpenCode.


#### nix

**Добавляйте** только если в описании проблемы явно упоминается nix.

Если в описании проблемы nix не упоминается, не добавляйте nix.

Если в описании проблемы упоминается nix, назначьте задачу `rekram1-node`.

#### zen

**Добавляйте** только если в описании проблемы упоминаются «zen», «opencode zen» или «opencode black».

Если в описании проблемы нет слов «zen» или «opencode black», не добавляйте метку zen.

#### core

Используйте для основных проблем сервера в `packages/opencode/`, за исключением `packages/opencode/src/cli/cmd/tui/`.

Примеры:

- Поведение LSP-сервера
- Поведение Harness (агент + инструменты)
- Запросы на добавление функций в поведение сервера
- Формирование контекста агента
- Конечные точки API
- Проблемы интеграции с провайдерами
- Новые, неработающие или некачественные модели

#### acp

Если в проблеме упоминается поддержка acp, присвойте ей метку acp.

#### docs

Добавьте, если в проблеме запрашивается улучшенная документация или обновление документации.

#### opentui

Проблемы TUI, потенциально вызванные нашей базовой библиотекой TUI:

- Не работают сочетания клавиш
- Проблемы со скоростью прокрутки (слишком быстро/медленно/с задержками)
- Мерцание экрана
- Сбои с opentui в логе

**Не** добавляйте для общих ошибок TUI.
