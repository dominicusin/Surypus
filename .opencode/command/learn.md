Проанализируйте эту сессию и извлеките неочевидные выводы для добавления в файлы AGENTS.md.

Файлы AGENTS.md могут находиться на любом уровне каталога, а не только в корне проекта. Когда агент считывает файл, любые файлы AGENTS.md из родительских каталогов автоматически загружаются в контекст считываемого инструмента. Размещайте полученные знания как можно ближе к соответствующему коду:

- Знания, полученные в рамках всего проекта → корневой файл AGENTS.md
- Знания, специфичные для пакета/модуля → packages/foo/AGENTS.md
- Знания, специфичные для конкретной функции → src/auth/AGENTS.md

Что считается полученными знаниями (только неочевидные открытия):

- Скрытые взаимосвязи между файлами или модулями
- Пути выполнения, отличающиеся от того, как выглядит код
- Неочевидные конфигурации, переменные окружения или флаги
- Прорывы в отладке, когда сообщения об ошибках были вводящими в заблуждение
- Особенности API/инструментов и обходные пути
- Команды сборки/тестирования, не указанные в README
- Архитектурные решения и ограничения
- Файлы, которые должны изменяться одновременно

Что НЕ следует включать:

- Очевидные факты из документации
- Стандартное поведение языка/фреймворка
- То, что уже есть в файле AGENTS.md
- Подробные пояснения
- Значения, специфичные для сессии Подробности

Процесс:

1. Анализ сессии на предмет обнаруженных ошибок, ошибок, потребовавших нескольких попыток, неожиданных подключений.
2. Определение области применения — к какому каталогу относится каждое полученное обучение?

3. Чтение существующих файлов AGENTS.md на соответствующих уровнях.
4. Создание или обновление файла AGENTS.md на соответствующем уровне.
5. Содержание записей должно составлять 1-3 строки на каждое полученное сообщение.

После обновления, суммирование того, какие файлы AGENTS.md были созданы/обновлены и сколько обучающих данных было получено из каждого файла.
