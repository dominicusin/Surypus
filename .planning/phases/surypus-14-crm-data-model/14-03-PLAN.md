Add RBAC security for all CRM endpoints and event sourcing for audit trail.

**Purpose:** Every CRM API mutation is access-controlled via RBAC and recorded to the event_store for full audit trail. This implements requirements CRM-04 (access control) and CRM-07 (event sourcing audit).

**Key design decisions:**
1. Six CRM permissions: CRMContactRead, CRMContactWrite, CRMDealRead, CRMDealWrite, CRMLeadRead, CRMLeadWrite
2. Permission text strings: "crm_contact:read", "crm_contact:write", "crm_deal:read", "crm_deal:write", "crm_lead:read", "crm_lead:write"
3. Three event aggregates: "crm_contact" (Int64 bigint_event_id), "crm_company", "crm_deal"
4. Event sourcing called AFTER the DB mutation in CRM.hs handlers (fire-and-forget pattern)
5. Follow exact pattern from `Infrastructure.EventStore.Accounting`

```haskell
data AccountingEvent = AccountCreatedEvent AccountCreated | ... deriving (Show, Eq, Generic)
$(deriveJSON defaultOptions ''AccountingEvent)

-- Event store wrapper using DAL.EventStore
data AccountingEventStore = AccountingEventStore { aesPool :: Pool, aesStreamName :: Text }
mkAccountingEventStore :: Pool -> Text -> AccountingEventStore

getEventInfo :: AccountingEvent -> (Int64, Text, Text)  -- (aggregateId, aggregateType, eventType)

appendAccountingEvent :: AccountingEventStore -> AccountingEvent -> IO (Either Text ())
appendAccountingEvent store event = do
  let (aggId, aggType, evType) = getEventInfo event
  latestSeqRes <- ES.getLatestSequence (aesPool store) aggId aggType
  case latestSeqRes of
    Left err -> pure $ Left err
    Right latestSeq ->
      ES.appendEvent (aesPool store) aggId aggType evType 1 (toJSON event) Nothing (latestSeq + 1)
```
