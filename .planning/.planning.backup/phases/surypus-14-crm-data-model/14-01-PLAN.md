<objective>
Create CRM database tables and domain types.

**Purpose:** Foundation for all CRM operations — persistent storage schema and Haskell domain types that every subsequent plan imports.

**Output:** DB migration V182 + V183, 7 new Haskell modules in `src/CRM/`, updated `Surypus.cabal`

**Critical design decisions:**
1. CRM tables use **UUID PK** (per V181 pattern). Add `bigint_event_id BIGSERIAL` column in each table for event store compatibility (DAL.EventStore uses Int64 `aggregate_id`).
2. `crm_companies` table has UUID PK + `person_id BIGINT REFERENCES persons.person(id)` to link existing person records.
3. V181 had `crm_deals.person_id UUID REFERENCES persons(id)` — **CORRECT in V182**: use `BIGINT` since `persons.person(id)` is `BIGSERIAL`.
4. V181 had `crm_deals.company_id UUID REFERENCES companies(id)` — `companies` table does not exist. V182 creates `crm_companies(id UUID)` so this FK in V181 references the new table naturally.
5. Three event aggregates: `"crm_contact"`, `"crm_company"`, `"crm_deal"`.
</objective>

       - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`

       - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
       - `stage_id UUID REFERENCES crm_pipeline_stages(id) ON DELETE CASCADE`
       - `rule_type TEXT NOT NULL CHECK(rule_type IN ('entry', 'exit'))`
       - `criteria_type TEXT NOT NULL` — e.g. 'min_deal_value', 'required_field', 'document_uploaded'
       - `criteria_config JSONB DEFAULT '{}'::JSONB` — flexible configuration
       - `created_at TIMESTAMPTZ DEFAULT NOW()`
       - Index: `idx_crm_pipeline_rules_stage` on stage_id

    4. Creates `crm_deal_stage_history` table for tracking stage transitions:
       - `id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
       - `deal_id UUID REFERENCES crm_deals(id) ON DELETE CASCADE`
       - `from_stage_id UUID REFERENCES crm_pipeline_stages(id)`
       - `to_stage_id UUID REFERENCES crm_pipeline_stages(id) NOT NULL`
       - `changed_by BIGINT` (user id)
       - `reason TEXT`
       - `changed_at TIMESTAMPTZ DEFAULT NOW()`
       - Index: `idx_crm_stage_history_deal` on deal_id

Since ALTER TYPE of FK column is risky, leave V181 as-is (deals created before V182 with person_id as UUID will work). The **Haskell API** (`Surypus.API.CRM`) already passes person_id as `Text` and casts to UUID in SQL. Document this in a comment. For new V182 tables, use correct BIGINT FKs to `persons.person(id)`.
