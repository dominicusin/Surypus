<objective>
Implement pipeline forecast refresh, stage rules, and stage history tracking.

**Purpose:** Complete the pipeline/forecasting layer — the prediction engine that makes CRM valuable for sales management.

**What this plan delivers:**
1. `refreshPipelineForecast` — programmatically refresh the materialized view
2. `getStageRules` — query entry/exit criteria per pipeline stage
3. `getStageHistory` — query stage transition history for a deal
4. REST endpoints for all three

**Pipeline workflow:**
1. User moves deal from "Proposal" to "Negotiation" stage → API records transition in `crm_deal_stage_history` table + emits DealStageChanged event
2. Forecast endpoint refreshes `mv_crm_pipeline_forecast` MV
3. GET pipeline/forecast returns probability-weighted revenue per stage
4. GET pipeline/stages/:id/rules returns entry/exit criteria for that stage
5. GET deals/:id/history returns full stage transition timeline
</objective>

-- Existing materialized view
CREATE MATERIALIZED VIEW IF NOT EXISTS mv_crm_pipeline_forecast AS
SELECT d.tenant_id, s.stage_name, s.stage_order, s.stage_probability,
  COUNT(*) as deal_count, SUM(d.deal_value) as pipeline_value,
  SUM(d.deal_value * s.stage_probability / 100) as weighted_forecast
FROM crm_deals d JOIN crm_pipeline_stages s ON d.stage_id = s.id
WHERE d.is_active AND d.stage_id NOT IN (
  SELECT id FROM crm_pipeline_stages WHERE stage_name IN ('Closed Won', 'Closed Lost')
)
GROUP BY d.tenant_id, s.stage_name, s.stage_order, s.stage_probability;

    ```haskell
    crmDealStageUpdate :: Env -> Text -> Text -> Handler CRM.Deal
    crmDealStageUpdate env did stageId = do
      -- Get current stage before update (for history tracking)
      currentDeal <- liftIO $ CRM.getDeal (envPool env) did
      currentStage <- case currentDeal of
        QuerySuccess deal -> pure $ Just (dealStage deal)
        _ -> pure Nothing
      -- Perform the stage update
      result <- liftIO $ CRM.updateDealStage (envPool env) did stageId
      case result of
        QuerySuccess deal -> do
          -- Record the transition in history
          _ <- liftIO $ CRM.recordStageTransition (envPool env) did
            (Just did)  -- dealId
            Nothing     -- fromStageId (stored as Text, not UUID — skip for now)
            (Just stageId)  -- toStageId
            Nothing     -- reason
            Nothing     -- changedBy
          -- Also emit event via EventStore (if envCRMEventStore exists)
          pure deal
        QueryError err -> throwError $ err500 {errBody = LBS.encodeUtf8 $ "CRM error: " <> TL.fromStrict err}
    ```

    Note: The `recordStageTransition` takes UUID text parameters. The current stage info from `currentDeal` gives us `stage_name` (Text) but we need the stage UUID. Since the `Deal` type has `dealStage :: Text` which is the *name*, not the UUID, we pass `currentStage` as fromStageId — the actual stage UUID text would need to be fetched via pipeline stages query. For this implementation, pass `currentStage` as a placeholder. A future refinement can look up the UUID by stage name.
