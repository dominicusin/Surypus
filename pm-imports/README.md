PHASE 2-3 Backlog Imports
This folder contains compact artifact files suitable for importing into common PM tools (Jira, YouTrack, Trello).

- jira-ph2-3.csv — Jira import sample (Phase 2-3 backlog)
- youtrack-ph2-3.json — YouTrack import sample
- trello-ph2-3.csv — Trello import sample

Usage guidance:
- Export compatible formats from your PM tool of choice using these templates as starting data.
- Review and adjust Epic/Story links as per your project structure.
