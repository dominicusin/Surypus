## Our Community

Surypus is a welcoming community of developers, users, and contributors who believe in the power of formal verification and type safety. We value:

- **Respect** - Treat everyone with dignity and respect
- **Collaboration** - Work together to build something great
- **Learning** - Help each other grow and learn
- **Quality** - Strive for excellence in everything we do
- **Transparency** - Be open and honest in our communications

## How to Contribute

### First Time Contributors

New to Surypus? Here's how to get started:

1. **Read the documentation** - Start with [README.md](../README.md) and [CONTRIBUTING.md](../CONTRIBUTING.md)
2. **Find a good first issue** - Look for issues labeled [good first issue](../../labels/good%20first%20issue)
3. **Ask questions** - Don't hesitate to ask if something is unclear
4. **Start small** - Documentation fixes, typo corrections, and small bug fixes are great ways to start

### Ways to Contribute

There are many ways to contribute to Surypus:

- **Code** - Fix bugs, add features, improve performance
- **Documentation** - Write guides, improve README, create tutorials
- **Testing** - Write tests, report bugs, verify fixes
- **Design** - Improve UI/UX, create graphics, design logos
- **Community** - Answer questions, help others, organize events
- **Translation** - Translate documentation and UI
- **Donations** - Support the project financially

### Contribution Process

1. **Fork** the repository
2. **Create a branch** for your changes
3. **Make your changes** following our guidelines
4. **Write tests** for new functionality
5. **Update documentation** if needed
6. **Submit a pull request**
7. **Respond to feedback** from reviewers

## Code of Conduct

Our community adheres to the [Code of Conduct](../CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code. Please report unacceptable behavior to the maintainers.

## Recognition

We recognize contributors in several ways:

- **Release notes** - Significant contributions are mentioned in release notes
- **Contributors page** - All contributors are listed on the [contributors page](../../graphs/contributors)
- **Badges** - Contributors receive badges on their GitHub profile
- **Shoutouts** - We regularly thank contributors on social media
