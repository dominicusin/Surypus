# Leadership

This document describes the leadership roles in the Surypus project and how to get involved.

## Leadership Roles

### User → Contributor → Committer → Maintainer → Core Team

```
User → Contributor → Committer → Maintainer → Core Team
 │         │            │            │            │
 │         │            │            │            └─ Project direction, mentorship
 │         │            │            └─ Commit access, releases, CoC
 │         │            └─ Direct commit access, PR review
 │         └─ Merged PRs, quality contributions
 └─ Uses project, reports bugs, suggests features
```

### Role Descriptions

#### Users
- Use Surypus
- Report bugs and suggest features
- Contribute to documentation

#### Contributors
- Have merged PRs
- Follow the Code of Conduct
- Help other contributors

#### Committers
- Direct commit access
- Review PRs from others
- Help maintain code quality
- **How to become**: 3+ months, 10+ merged PRs, nominated by maintainer

#### Maintainers
- Set project direction
- Manage releases
- Enforce Code of Conduct
- **How to become**: Long-term commitment, leadership skills

#### Core Team
- Provide architectural guidance
- Mentor maintainers
- Make strategic decisions

## How to Get Involved

1. **Start contributing** - Make quality contributions consistently
2. **Help others** - Answer questions, review PRs, mentor
3. **Take ownership** - Own features or areas of the project
4. **Grow** - Take on more responsibility over time

## Recognition

All leaders are recognized in:
- README.md
- Release notes
- GitHub contributors page
