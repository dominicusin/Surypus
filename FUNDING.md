# Funding Surypus

Surypus is an open source project maintained by volunteers. This document explains how you can support the project financially.

## Why Funding Matters

Open source software powers the modern web, but most of it is built and maintained by volunteers. Financial support helps:

- **Sustain development** - Pay for development time, infrastructure, and tools
- **Ensure longevity** - Keep the project alive and maintained long-term
- **Enable contributions** - Allow people from all backgrounds to contribute
- **Support users** - Provide better documentation, support, and features

## Ways to Support

### GitHub Sponsors

The easiest way to support Surypus is through [GitHub Sponsors](https://github.com/sponsors/dominicusin). You can make a one-time or recurring donation.

**Benefits:**
- 100% of funds go to the maintainer (GitHub takes 0% for verified accounts)
- Instant setup via GitHub
- Public recognition (optional)

### Open Collective

We use [Open Collective](https://opencollective.com/surypus) for transparent budgeting and expense tracking.

**Benefits:**
- Full transparency on how funds are used
- Invoices and receipts for companies
- Community voting on budget allocation (coming soon)

### In-Kind Contributions

Not all support is monetary. We also welcome:

- **Infrastructure** - Hosting, CI/CD resources, domain names
- **Services** - Legal, accounting, marketing
- **Equipment** - Hardware for development and testing

## How Funds Are Used

### Priority Allocation

1. **Development time** - Pay for core maintainer time
2. **Infrastructure** - Hosting, domains, CI/CD
3. **Documentation** - Technical writing, translations
4. **Community** - Events, meetups, conferences
5. **Bounties** - Pay for specific features or fixes

### Transparency

All income and expenses are tracked on our [Open Collective](https://opencollective.com/surypus) page. We publish quarterly financial reports.

## Tax Deductibility

Surypus is not a registered nonprofit organization. Donations are not tax-deductible in most jurisdictions.

For companies that require tax-deductible donations, we can work with a fiscal sponsor. Please contact us for details.

## Recognition

- Release notes - Mention in project releases
- README - Logo placement (for corporate sponsors)
