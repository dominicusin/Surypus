## How to Become a Listed Contributor

We recognize all types of contributions:

- 💻 **Code** - Bug fixes, features, performance improvements
- 📖 **Documentation** - Guides, tutorials, translations
- 🐛 **Bug reports** - Detailed issue reports
- 💡 **Ideas** - Feature requests and discussions
- 🤝 **Community** - Helping others, answering questions

After your first merged contribution, you'll be added to this list.

## Recognition

All contributors are also recognized in:

- [GitHub Contributors](https://github.com/surypus/surypus/graphs/contributors)
- Release notes for significant contributions
- Project documentation
