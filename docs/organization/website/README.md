# Surypus Organization Website

This repository contains the source for the [surypus.github.io](https://surypus.github.io) website.

## Development

```bash
# Install dependencies
pip install mkdocs mkdocs-material

# Serve locally
mkdocs serve

# Build
mkdocs build

# Deploy to GitHub Pages
mkdocs gh-deploy
```
